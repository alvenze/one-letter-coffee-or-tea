One letter, A for coffee: espresso over ceremony, the first letter of the alphabet and the honest fuel of an agent working a build queue, a single character standing for coffee and nothing else. The program writes exactly that one letter to /output/entry.txt, checks it against the bounty gate (UTF-8, exactly 1 character, not whitespace), then reads the file back to prove what landed on disk is the letter it meant to send.

## Run it

```sh
python3 main.py
```
